CKAN Search and DCAT Reference

Quick links for searching this CKAN catalog and checking DCAT export endpoints. Use these as examples for users and integrators.

CKAN UI Search

  • /dataset?q=tram (general dataset search)
  • /dataset?q=tram+metro (multi-keyword example)

CKAN API Search (package_search)

  • /api/3/action/package_search?q=title:tram&rows=20
  • /api/3/action/package_search?q=notes:tram&rows=20
  • /api/3/action/package_search?q=title:tram OR notes:tram&rows=20
  • /api/3/action/package_search?q=tram&rows=20&start=0

Use start and rows for paging through large catalogs.

DCAT / DCAT-AP Endpoints

  • /catalog.rdf
  • /catalog.ttl
  • /catalog.jsonld
  • /dataset/amsterdam-open-geodata-522-tram-en-metrolijnen-2019.jsonld

DCAT-AP standardizes metadata format, not catalog search API syntax.

Notes

  • Use CKAN search endpoints for discovery.
  • Use DCAT endpoints for interoperable metadata exchange and harvesting.
  • For very large catalogs, avoid scanning full /catalog.jsonld for keyword search.
